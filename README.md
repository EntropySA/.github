# Entropy GitHub Profile

Entropy organization profile assets and GitHub community configuration.

## What is in this repository

- Organization-facing introduction and product information live in `profile/README.md`.
- `Entropy.png` is the shared organization branding asset.
- The root README documents this configuration repository; it is not an application repository.

## Project layout

- [`profile`](profile) — Organization profile shown on GitHub.

## Maintaining the organization profile

Edit [`profile/README.md`](profile/README.md) to update the introduction displayed on the organization profile. Keep company/product information consistent with the public website. This repository is public: do not add private repository lists, customer details, internal endpoints, or credentials.
